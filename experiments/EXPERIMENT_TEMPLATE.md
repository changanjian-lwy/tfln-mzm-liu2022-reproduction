# 实验文档模板

依据 [项目边界](../docs/BOUNDARIES.md) 第 5、7、11 节，借鉴 AES 的 `EXPERIMENT_BOUNDARY_TEMPLATE.md`。A06 起所有实验使用本模板；A00–A05 早于本模板，不追溯改写。

## BOUNDARY.md（运行前单独提交，不超过 70 行）

```
# A__ - <改变的变量>（BOUNDARY）
运行前提交。父实验：<编号、提交号>。事前看过：<父实验 RESULTS、相关 C-xx 记录；没有就写无>。
模型层级：<L0/L1/L2/L3，只选一个>。等级上限：<例如 SENSITIVITY_ONLY>。
改变哪个决定或结论：<一句话；说不出就不做>。
更便宜的检查：<已有输出、解析估算或现有 json；或说明为何不够>。
参考做法：<论文段落、引文、课程材料；没有来源的标为项目决定>。
预算：墙钟 <N> 秒、新增磁盘 <M> MB。

## 0. 运行前五问（docs/BOUNDARIES.md 第 5 节）
1 等效电路：___  2 端口与约定：___  3 输入提供者唯一：___
4 参数来源（含 C-xx 分支编号）：___  5 结论边界：___
任何一条为"否/未定" -> 不运行。

## 1. 问题与方法
- 问题与假设（2-3 条），什么结果会反驳它
- 只改变：___；保持固定：L、Vg、Zg、负载、f0、插值规则、数字化数据哈希
- 运行顺序：G1 方法检查 -> ___；每一步通过后才进入下一步

## 2. 判据（运行前写死，带数字）
| # | 关卡 | 判据 | 适用对象 |
G1 方法（单元测试 + check_evidence + 复现父实验关键数字）/ G2 数值（收敛、有限性、被动性）/
G3 对照（支持区间、误差随附）/ G4 结论阈值。不适用的写明理由。

## 3. 预测（不是判据）
数字预测及依据。

## 4. 决策规则与停止条件
通过 -> ___；失败 -> ___；立即停止并问用户：扩大范围、放宽判据、升级分支为主线、推送。
本轮能下的结论：___；不能下的结论：___。
```

```

```
