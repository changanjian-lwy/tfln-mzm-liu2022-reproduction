# O02 - 从截面求电光重叠 Γ 与 VπL（BOUNDARY）

运行前提交。父实验：O01（结果 `e06df9a`；用其 N 配置的 TE0 与网格规则）。事前看过：O01 全部输出；论文 p.856 的 Vπ 段落（1 MHz 三角波、开路终端、Vπ 2.7 V、6 mm、VπL 1.62 V·cm）；引文 [10] 的 Eq.(1)(2)、r33 = 31 pm/V、占空比 90%；`data/external/dc_materials/SOURCE.md`；课程 Lecture 4 p.22；本项目 `static.py`。**运行前没有求解过任何静电场，也没有算过任何 Γ。**
模型层级：O-L2（光模式 + 准静态电场，二维截面）。等级上限：`DIAGNOSTIC_ONLY`。
改变哪个决定或结论：论文的 VπL = 1.62 V·cm 能否由它给出的截面独立算出；如能，占空比要多大。
更便宜的检查（已做）：Γ = 1（均匀场 V/g、模式全在 LN）时 VπL = λg/(2 n_e³ r33) = 0.768 V·cm（1550 nm、r33 = 31 pm/V）；实测 1.62 V·cm 要求 Γ·D ≈ 0.47（波长与 r33 取值内 0.44–0.48）。Γ 要靠场计算。
参考做法：约定 A 取自引文 [10] Eq.(1)(2)，与 Lecture 4 p.22 的 Δn = ½ n_e³ r33 E 及 `static.py` 一致；约定 B 是一阶微扰的直接实现（改 ε 重解模式）。
预算：`BUDGET.json` 强制执行：总墙钟 ≤2400 s、单次求解 ≤180 s、网格 ≤400k 单元、求解 ≤200 次、新增磁盘 ≤5 MB、峰值内存 ≤10 GB。预计 10–20 分钟。任一上限触发 → 停止，保存部分记录，向用户报告。

## 0. 运行前五问
1 等效电路：不适用。物理模型：二维截面过 T 头；1 MHz 按静电场处理；推挽，两臂几何相同、场反向；T 头之间的空隙（占空比 D）当作无场，VπL = VπL_轨 / D。
2 端口与约定：坐标同 O01（x = 晶体 Z）；半域 x ≥ 0：光学同 O01（x = 0 为 PEC），静电 x = 0 为 φ = 0（两轨 ±V/2，间隙电压 V），右轨整块 φ = V/2，其余外边界为自然边界（法向 D = 0）；φ 用二阶 P2 单元，E = −∇φ。ε_DC,LN = diag(ε33, ε11)。λ、g、L 单位分别 µm、µm、cm。
   约定 A：Γ = (g/V)·∬_LN E_x |E_x,opt|² dA / ∬_全域 |E_x,opt|² dA（引文 [10] Eq.(2)，"沿 Z 方向的场"）；VπL_轨 = λg/(2 n_e³ r33 Γ)，n_e 取该波长的 Zelmon CLN 值。
   约定 B：LN 单元的光频 ε_xx 加 Δε = −n_e⁴ r33 ⟨E_x⟩（⟨⟩ 为单元平均），在 V = ±10 V 各解一次 TE0，dn/dV = [n(+10) − n(−10)]/20；VπL_轨 = λ/(2|dn/dV|)。不计 r13（它作用于 n_o，TE0 的 E_y 能量只占约 0.7%）。
3 输入提供者唯一：几何同 O01；光学材料同 O01；低频常数只取 `dc_materials/SOURCE.md`；同一网格上先解光模式、再解静电场。
4 参数来源：第 1 节表。5 结论边界：只回答 VπL 与 1.62 V·cm 是否相容、需要的占空比范围；不推出射频 Γ(f)、带宽、损耗、Figure 3 的任何结论。

## 3. 预测（不是判据）
N：Γ_A 约 0.50–0.60；VπL_轨 约 1.3–1.5 V·cm，除以 0.9 后约 1.45–1.7。约定 B 的 VπL 比 A 低 3–10%。主导因素：力学状态（ε11 44 对 85）、T 头厚度与宽度、SiO2 ε；波长约 ±1.3%。结论：约定 A 更可能"相容"，其次"不定"。

不调 D、r33、ε 或几何去凑 1.62；看到结果后不改端点、判据数字或约定定义。两种约定的结论分开写，不合并成一个。

## 5. 运行前修订（2026-10-05 13:35，边界提交 `2f66d0f` 之后、脚本提交与运行之前；判据 1–4 的数字、预算、因素与端点、实测带都不变）
- **约定 B 的公式笔误**：推挽两臂各变 ±(dn/dV)·V，相位差为 (4π/λ)(dn/dV)VL，所以 VπL_轨 = λ/(4\|dn/dV\|)；第 0 节第 2 条写成 λ/(2\|dn/dV\|) 是笔误，会让 B 在同一 Γ 下比 A 大 2 倍。单元测试（dn/dV 取约定 A 的 ½n_e³r33Γ/g 时两式应相等）发现。
- **两套网格**：第 0 节第 3 条"同一网格"改为两套。光模式用 O01 的半域网格（规则与计算域都同 O01）；电势用放大的半域网格（x∈[0, 20d]、y∈[−2−18d, 0.6+20d]，网格规则同 O01）。P2 电势的梯度在每个单元上恰好是线性的，所以用 DG-P1 无损表示，再在光学网格的积分点上取值。原因：按 O01 的远场网格尺寸，放大的计算域在 m = 2、1 时有 21.6k、78.5k 个单元（只建网格、没有求解），外推光模式单次约 50 s、200 s，后者超过 180 s 上限，整轮也远超 40 分钟。计算域检查（d = 1 对 2）现在只作用于电势网格；光学计算域已由 O01 检查过。判据 1 的父实验复现因此是同一网格上的比较，阈值仍为 1e-4。
- **积分规则**：光模式求解保持 O01 的配置（femwell 从 P0 基继承的 3 点规则，见 ERRATA E-03：改用 4 阶时 N 的 ng 只变 3.2e-6）。Γ 的被积函数 E_x,rf·\|E_x,opt\|² 是 5 次多项式，所以 Γ 与约定 B 的单元平均场在新建的 6 阶积分基上计算（同一单元，自由度编号相同）。
- **披露**：在非 Liu 截面（膜厚 1.0、刻蚀 0.5、脊宽 2.0、间隙 6 µm；网格 m = 8/4；阈值临时放宽；输出写在仓库外）上干跑了两次（单网格 130 s；两套网格 34 s），只看了状态、G1 两层电容误差（约 1e-14）、角点的选择与计时，没有看那个截面的 Γ 或 VπL 数值，也没有看图。**仍然没有求解过 Liu 截面的静电场。**
