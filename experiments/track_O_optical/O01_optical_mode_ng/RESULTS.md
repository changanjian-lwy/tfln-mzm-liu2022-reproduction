# O01 - 从截面几何求光模式群折射率 ng（RESULTS）

等级：`DIAGNOSTIC_ONLY`。范围：O-L2 光频截面本征模，TE0，同成分 LN，λ = 1530–1570 nm，半域加 PEC 对称面；只对照"ng ∼ 2.25"（p.857），与 Figure 3 无关。边界提交 `65efa21`；运行前修订 `62c741f`；脚本 `3a3278e`。

## 0. 结论
1. **按事前规则"不定"。** 在声明的范围内（λ 1530–1570 nm、侧壁角 60–90°、1 µm 为顶宽或底宽、PECVD 折射率 +0 至 +0.02、两种衬底、T 形电极无或厚 0.2–0.8 µm），论文给出的截面算出的 TE0 群折射率为 **2.2814–2.2861**（13 个配置；数值不确定度 u = 7.8e-6）。对照区间与 [2.245, 2.255] 不相交，所以不是"相容"；落在 [2.20, 2.30] 内，所以也不是"不相容"。
2. 名义配置 N（1550 nm、75°、顶宽 1 µm、电极厚 0.5 µm）：Re n_eff = 1.89762，**ng = 2.28374**，TE 分数 0.993。比"∼2.25"高 0.034（1.5%），比体材料 n_e 的群折射率 2.1823 高 0.101（波导色散）。
3. 声明的因素影响都很小：宽度定义（底宽 +0.0018）与侧壁角 60°（−0.0018）最大；PECVD 折射率 +0.02 为 −0.0005；波长 ±20 nm 为 ∓0.0002；T 形电极有无 <5e-5；衬底 <1e-9。区间宽 0.0047，远小于它与 2.25 的距离。
4. 并报（不进区间、不进结论）：5% MgO 分支 ng = 2.27388（比 N 低 0.0099）。
5. 按边界第 4 节，O02 用 N 的模式，区间端点用两个角点。

角点（直接求解）：低角点 1570 nm、60°、顶宽、PECVD +0.02、熔融石英、无电极，ng = 2.28138；高角点 1530 nm、75°、底宽、Malitson、晶体石英、电极厚 0.8 µm，ng = 2.28608。可加性诊断：单因素变化之和为 −0.00255 / +0.00203，实算为 −0.00237 / +0.00234。衬底一项的取值是舍入决定的：脚本拿全精度的 N 与保留 9 位有效数字的单因素值比较，而衬底的差只有 2.6e-10，所以低角点取了熔融石英（实际比晶体石英高 2.6e-10）。对区间的影响 <1e-9，远小于 u，不重跑。

预测对照：N 的 n_eff（1.86–1.95）与 ng（2.27–2.31）都在预测范围内；主导因素是侧壁角与宽度定义，对；波长、衬底各 <0.003，电极 <0.005，对；"不定"最可能，对；MgO 约 −0.01，对。**区间宽度预测错了**：预测 0.03–0.06，实际 0.0047，侧壁角与宽度定义的影响被高估了约 10 倍。网格预测"m = 1 即收敛"是修订前写的，实际 m = 2 已收敛。

## 2. 首个失败边界与下一步
没有关卡失败。"不定"就是结果：不调侧壁角、宽度、波长或折射率去凑 2.25，也不改 0.05 的宽带。与 2.25 的差（0.026–0.036）比任何一个声明因素大一个数量级以上，所以差异来自声明范围之外（事后观察见 OBSERVATION_posthoc.md）；那些可能性都没有检验，要检验任何一项都得另立实验，由用户决定。主线 ng = 2.25 不改：把 O01 的值升级为主线，由用户决定。下一步是 O02（边界先行，用 N 的模式）。

## 3. 限制
- 只算二维截面；T 形电极只取整段有或整段无两端，占空比与 T 头之间的空隙没有建模（电极有无对 ng 的影响 <5e-5）。
- 膜厚、刻蚀深度、脊宽、覆盖层厚度都取论文名义值，没有加工公差分支；温度取材料数据的 20–21 °C；材料只用一组数据。
- PECVD 覆盖层按等厚、尖角处理；Fig.1(b) 只是示意图。

## 4. 对应课程概念
波导色散：模式群折射率 ng = n_eff − λ dn_eff/dλ 同时包含材料色散与波导色散；在高折射率对比的脊波导里，波导色散让 ng 比体材料高约 0.1。
