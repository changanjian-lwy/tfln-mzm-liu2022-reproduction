# O01 事后观察（不是判据）

O01 运行之后写的。只对 `results.json` 中已登记的数做算术，不新增求解，不改 O01 的输出与结论。

## 与 2.25 的差有多大
- 区间下端减 2.255 为 0.0264；最大的单因素变化是 0.00184（底宽），两者之比为 14.3。
- MgO 分支 2.27388 仍比 2.255 高 0.0189。MgO 的变化加上低角点的变化（相加估算，没有求解）为 2.27152，仍高 0.0165。
- 所以在本实验的声明范围、材料数据与二维模型内，"∼2.25"达不到。可能的来源都**没有检验**：膜厚或刻蚀深度偏离名义值；"∼2.25"是作者的近似值，或来自别的测量或仿真方法（论文没写 ng 是怎么得到的；引文 [10] 对它自己的器件也写"ng ∼ 2.25"）；材料数据与实际薄膜不同。要检验任何一项，都得另立实验，由用户决定。

## 对 Figure 3 主线的量级影响（只是估算）
- L1 主线把 nm 与 ng 都取 2.25（速度匹配）。如果 ng 实际是 2.2837（N）而 nm 仍是 2.25，L = 6 mm 的速度失配代价 −20·log10\|sinc(π f Δn L / c)\|（B04、M02 同式）为 0.016 dB（50 GHz）、0.065 dB（100 GHz）、0.262 dB（200 GHz）；用区间两端代入，200 GHz 为 0.23–0.30 dB。
- M02 读到的实测 nm 在 50–170 GHz 内与 2.25 相近，所以这只是量级参考，不是对主线的修正。把 O01 的 ng 用到 L1 主线属于升级分支（BOUNDARIES 第 6 节），由用户决定。

## 光损耗（边界不对照，只记录）
- N（电极整段存在）的模式损耗 0.107 dB/cm（m = 2；m = 1 为 0.105；Im 部分没有收敛判据）。按引文 [10] 的 90% 占空比线性折算约 0.096 dB/cm。引文 [10] 正文说 3 µm 间隙、100 nm 覆盖层时光吸收损耗可保持在 0.1 dB/cm 以下，两者量级一致。这里的损耗只来自金的吸收，依赖 Olmon 金数据和电极边缘的网格，不作结论。
