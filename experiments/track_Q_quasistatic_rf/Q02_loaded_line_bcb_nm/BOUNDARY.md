运行前提交，**在 Q01 运行之前**，所以对 Q01 的数是盲的。父实验：Q01（同一求解器、G1 基准、网格规则与 L_ext 的算法）；O01（波导截面 N）；O02（T 头尺寸范围）。事前看过：论文 p.855–856（"BCB 加厚 → 更多电场在低介电区 → nm 逐渐下降"；"调制电场主要在 T 形电极之间"；BCB 在调制臂周围选择性去除）；A06 的 Fig.2(b) 读数：t = 0.5 µm 为 2.2729 ± 0.0012，t = 3.5 µm 为 2.2251 ± 0.0010（各取 ±0.05 µm 内读数的中位数），星标 t = 1.5 µm 为 2.2500 ± 0.0005；`data/external/rf_materials/SOURCE.md`。**运行前没有解过任何射频截面。**
模型层级：Q-L2。等级上限：`DIAGNOSTIC_ONLY`。

更便宜的检查：没有闭式解（多层各向异性介质、两种高度的导体）；只知道方向：BCB 的 ε（2.5–2.65）远低于 LN 与 SiO2，加厚应使 C 与 nm 下降。
参考做法：周期加载线的准静态平均（引文 [10]："电容主要来自 T 形电极"）：C_avg(t) = (D − f_n)·C_H(t) + f_n·C_N(t) + (1 − D)·C_U(t)。C_H 是过 T 头、不过颈的截面（T 头是独立导体，电位同所属主电极）；C_N 是过颈的截面（颈从 T 头连到主电极，遇 BCB 侧壁则沿侧壁上爬）；C_U 是两段 T 头之间的无加载截面。nm(t) = c√(L·C_avg(t))，L 同 Q01。比值 r(t) = nm(t)/nm(1.5) = √(C_avg(t)/C_avg(1.5)) 与 L、L_int 都无关。
预算：`BUDGET.json`：总墙钟 ≤3600 s、单次求解 ≤120 s、网格 ≤400k 单元、求解 ≤400 次、新增磁盘 ≤5 MB、峰值内存 ≤8 GB。预计 20–40 分钟。

## 3. 预测（不是判据）
方向对（nm 随 t 下降）。幅度：Δ(0.5) 约 +0.01 至 +0.04，Δ(3.5) 约 −0.01 至 −0.03，两项最可能"相容"，其次"不定"。主导因素：LN 刻蚀范围与 BCB 窗口半宽（决定电极下方的高 ε 区），其次 ε_BCB；T 头尺寸对比值影响小。绝对 nm(1.5) 区间宽（T 头与颈的电容占大头），约 2.0–2.6，结论"不定"。
