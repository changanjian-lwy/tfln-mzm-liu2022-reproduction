## 0. 结论
1. **BCB 敏感度：两点按事前规则都"相容"。** 以 t = 1.5 µm 为锚，Δ(0.5) 的区间为 +0.0111 至 +0.0279（读数 +0.0229 ± 0.0013），Δ(3.5) 的区间为 −0.0367 至 −0.0126（读数 −0.0249 ± 0.0011）。名义配置 N 给出 +0.0196 与 −0.0255：后者在读数带内，前者比读数带低 0.0020。这个比值与 L 无关，所以不受 Q01 电感问题的影响。
2. N 的整条曲线（锚在 2.25）：t = 0 时 2.285，t = 4 µm 时 2.220；Fig.2(b) 两端的读数约为 2.29 与 2.226（A06）。论文"BCB 加厚使 nm 下降"的幅度可以由截面独立算出。
3. **绝对 nm(1.5)：按规则"相容"，但只在区间顶端。** 区间 1.991–2.255。N 用外电感时为 2.131（低 5.3%），加内电感上限为 2.164。够到 2.25 的只有 nm 高角点（T 头宽 3、厚 0.8 µm，颈占 0.1，窗口最小，只刻间隙，SiO2 ε 4.5，地宽 50 µm）再加内电感上限。N 要得 2.25 需要 C_avg = 188.4 pF/m，比算出的 169.0 pF/m 高 11.5%。
4. 对 Δ(0.5) 影响最大的是衬底（熔融石英 −23%）和 T 头宽（1 µm +18%、3 µm −12%），其次 BCB 窗口（−9%）和地宽 50 µm（+7%）；ε_BCB 2.5 为 +5%，刻蚀范围只有 −2%。对绝对 nm 影响最大的也是衬底（−0.061），其次是 T 头宽和 SiO2 的 ε。
5. 只报不判：准静态 Z0 = √(L/C_avg) 在全部配置中为 41.4–45.5 Ω（N 为 42.1 Ω），都低于 Fig.2(c) 在 100 GHz 的读数 46.8 Ω，与 Q01 同一方向。
6. 数值：父实验复现 L_ext 相对差 4.9e-6；网格 m = 2 对 1：C ≤5.9e-4、r ≤3.5e-5（N 与 5 个不同的角点）；计算域：C 3.5e-5、r 1.0e-5。

## 2. 首个失败边界与下一步
没有关卡失败。在声明的范围内，加载线截面能独立算出 Fig.2(b) 中 nm 随 BCB 厚度变化的幅度。绝对 nm 与 Q01 的 Z0 指向同一处：由主电极几何算出的 L 偏低（见 [事后观察](OBSERVATION_posthoc.md)）。不调 T 头、窗口、衬底或电极厚度去凑。如要继续，最直接的是只读文献、核对作者仿真里的电极厚度与地宽，需用户授权。

## 3. 限制
- 二维截面加权平均，忽略段与段之间的三维边缘场；颈所占长度比是假设。
- 理想导体、高频极限；内电感只给上限；ε_BCB 用 1–20 GHz 的数据表值外推到 100 GHz。
- 比较的是 nm 随 BCB 厚度的比值，不检验 nm 的频散。

## 4. 对应课程概念
行波电极的速度匹配：nm = c√(LC)；BCB 把主电极抬离高 ε 的 LN 与 SiO2，只降低电容的一部分，从而微调 nm。
