1. **电容接近论文所需，偏的是电感。** 论文的 nm = 2.25 与 Fig.2(c) 在 100 GHz 的 46.77 Ω 合起来要求 L = 351.0 nH/m、C = 150–190 pF/m 量级。N 算出的 C_avg(1.5) = 169.0 pF/m：配 Q01 算出的 L = 299.0 nH/m，得 nm 2.131、Z0 42.1 Ω（分别低 5% 与 10%）；配论文隐含的 L = 351.0 nH/m，得 nm 2.309、Z0 45.6 Ω（分别高 2.6% 与低 2.6%）。也就是说，截面电容与论文的两个数大体相容，不自洽集中在主电极电感上，与 Q01 的事后观察一致（作者的模型可能电极更薄或地线更窄；没有检验）。
2. **曲线形状。** N 的 Δ(3.5) 落在读数带内，Δ(0.5) 低 0.0020：算出的曲线在 t < 1.5 µm 处比 Fig.2(b) 略平。没有检验原因。
3. **衬底是最大的单因素。** 论文只写"石英衬底"，晶体石英还是熔融石英未知（O01、O02 也把它作为分支）；这一项对 Δ(0.5) 的影响（−23%）比 T 头尺寸还大。
