# Q01 - 主电极外电感 L 与 Fig.2(c) 的 Z0 是否自洽（BOUNDARY）

运行前提交。父实验：O02（`eo_overlap.solve_potential`：各向异性 P2 拉普拉斯，G1 两层电容误差 ≤1.8e-14）；输入来自 A03（Fig.2(a)(c)）与 A06（Fig.2(b) 星标）。事前看过：论文 p.855–856（主电极尺寸、BCB、500 µm 石英加 2 µm 键合 SiO2）；引文 [10] Eq.(4) 与"电感主要取决于中心信号线宽和非加载电极间距"一句；Fig.2(c) 在 90–110 GHz 的读数带 43.78–48.80 Ω、10–200 GHz 的读数带 36.12–55.74 Ω；Fig.2(a) 在 95–105 GHz 的读数上限 59.2 Np/m；下面"更便宜的检查"里的闭式数。**运行前没有用有限元解过任何射频截面，包括基准。**
模型层级：Q-L2（准静态射频截面：理想导体、二维、高频极限）。等级上限：`DIAGNOSTIC_ONLY`。
改变哪个决定或结论：论文给出的主电极几何、nm(100 GHz) = 2.25 和 Fig.2(c) 的 Z0 在准 TEM 关系下是否自洽；关系到 C-01（Fig.2(c) 的 Z0 是什么）与 S11 未复现的原因候选。
更便宜的检查（已做）：零厚度 CPW 的保角变换（有限宽地线，Ghione & Naldi, IEEE T-MTT 35(3), 1987）：s = 80、g = 20 µm，地宽 50/150/500/∞ µm 时 L = 358/337/331/331 nH/m，配 nm = 2.25 得 Z0 = 47.7/44.9/44.2/44.0 Ω，落在读数带附近。4 µm 金厚会使 L 降低，t/g = 0.2 时薄导体修正不可靠，幅度要靠数值解。
参考做法：L = 1/(c²C0)，C0 是介质全部换成真空、只含载流导体（信号线与两条地线）时的单位长度电容；由 Z0 = √(L/C)、nm = c√(LC) 消去 C 得 Z0 = cL/nm（引文 [10] Eq.(4)）。理想导体的 C0 给出外电感，即高频极限；趋肤效应区内电感 L_int = R/ω，且 R ≤ 2·Z0·α。
预算：`BUDGET.json` 强制执行：总墙钟 ≤1200 s、单次求解 ≤120 s、网格 ≤400k 单元、求解 ≤80 次、新增磁盘 ≤5 MB、峰值内存 ≤8 GB。预计 5–10 分钟。任一上限触发 → 停止，保存部分记录，向用户报告。

## 0. 运行前五问
1 等效电路：Fig.1(c) 的均匀传输线（Z0、nm），论文 Eq.(1)–(3)。本实验只用准 TEM 关系、只在 100 GHz 一个频点，不进入 Eq.(1)–(4)。
2 端口与约定：x 横向，x = 0 为信号线中心；y 向上，y = 0 为键合 SiO2 顶面（同 O01）。半域 x ≥ 0，x = 0 为自然边界（偶对称：信号 φ = V、两地 φ = 0）；外边界 φ = 0（屏蔽盒，由 d 检查）；导体内部全部自由度固定。C = ε0·φᵀAφ/V²，乘 2 得全截面。T 形电极不载纵向电流（引文 [10]；assumption），所以 L 只由主电极决定，与介质和 T 形电极无关。
3 输入提供者唯一：几何只取论文正文；nm 只取 A06 星标 2.2500 ± 0.0005；Z0 只取 A03 的 Fig.2(c)；损耗只取 A03 的 Fig.2(a)。

## 3. 预测（不是判据）
4 µm 金厚使 L 比零厚度低 5–10%：N 的 L_ext 约 305–320 nH/m，Z0_pred 约 41–44 Ω（加 L_int 上限再高约 1.2 Ω）。结论最可能"不定"（略低于近带），其次"相容"；相容所需的地宽 ≤100 µm。
