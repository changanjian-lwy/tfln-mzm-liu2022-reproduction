# B04 - 微波–光速度失配扫描（RESULTS）

等级：`SENSITIVITY_ONLY`。范围：Track B；A04 L1 提供者，只改 nm=ng+Δn，Δn ∈ {−0.10, −0.05, 0, +0.05, +0.10}；ZL=40/50 Ω。边界提交：`30cdcfd`。

## 0. 结论（模型敏感性）
1. 失配主要影响高频：40 Ω 时 200 GHz 处 M = −3.21 / −1.47 / −0.87 / −1.44 / −3.22 dB（Δn = −0.10 → +0.10）；0–50 GHz 起伏只从 1.06 dB 变到 1.15 dB 以内。
2. D1：40 Ω 时 \|Δn\|≤0.05 不跌破，\|Δn\|=0.10 为 141.3 GHz；50 Ω 时 Δn=0 为 141.8 GHz，\|Δn\|=0.05 约 132 GHz，\|Δn\|=0.10 为 112.0 GHz。
3. **±Δn 几乎对称**：同一 \|Δn\| 下 200 GHz 处 M 相差 ≤0.031 dB，可比的 D1 相差 ≤0.32 GHz；P50 有 0.03–0.06 dB 的小不对称。
4. 论文 Fig.2(b) 的 BCB 0–4 µm 对应 Δn 约 −0.024 到 +0.040（A06），落在本扫描 \|Δn\|≤0.05 的范围内：在这个范围内，40 Ω 终端时 200 GHz 内仍不跌破 −3 dB。即在 L1 输入下，BCB 厚度的工艺偏差对带宽的影响远小于损耗和终端的影响。

## 2. 限制
- 改 nm 时保持 Z0 不变；真实器件里改 BCB 会同时改 Z0 和损耗（A08 也指出了这一点）。
- nm 无色散的假设不变。

## 3. 对应课程概念
行波调制的速度匹配：失配引入 sinc 型走离，带宽 ∝ 1/(\|Δn\|·L)；损耗存在时，小失配的影响被损耗掩盖。
