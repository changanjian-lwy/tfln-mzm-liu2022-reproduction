# B05 - (ZL, L) 联合设计空间：网格真值与贝叶斯优化（RESULTS）

等级：`SENSITIVITY_ONLY`。范围：Track B / SC-04；A04 L1 提供者，ZL 10–120 Ω × L 1–30 mm 联合，64 311 个网格点；受支持频点 2.225–197.775 GHz。边界提交：`46ade0c`；脚本 `35c63b2`。

## 0. 结论（L1 输入下的模型结果，不是器件预测）
1. **方法（ML）**：GP 代理 + 约束期望改进在 B=50/100/150 GHz 三个目标上 30/30 个种子都在 40 次求值内找到网格最优（差 ≤0.1 dB），所需求值次数中位数 9 / 11 / 12.5、最多 12 / 16 / 20，约为网格的 0.014–0.019%。同样 40 次的随机搜索只成功 0/30、1/30、0/30。判据 5、6 通过。
2. **前沿**：只要求"归一化响应 ≥−3 dB、S11 ≤−10 dB（到 B 为止）"时，效率最优点 J* = +12.29 / +11.57 / +10.43 / +8.21 / +6.18 / +5.36 dB（B=50/75/100/125/150/175 GHz；B_full=197.775 GHz 与 175 GHz 相同），对应 ZL* = 35 / 30.5 / 25 / 23 / 23 / 23.5 Ω、L* = 30 / 30 / 29.9 / 24.5 / 19.4 / 17.4 mm。B=50、75 GHz 的最优落在 L=30 mm 边界，只是下界（图中没有标出这一点）。
3. **起约束作用的是 S11，不是带宽**：可行区左缘约 23 Ω，几乎不随 L 变；B≥125 GHz 时最优点的 S11 = −10.00 至 −10.18 dB，正好贴在约束上；所有最优点的 c1 都在 −2.92 至 −3.00 dB。优化器的做法是：把 ZL 压到 S11 允许的最低值，用低端失配做均衡，再用长度换效率。
4. **这个"最优"不平坦（事后观察，不是判据）**：各最优点到 B 的峰峰起伏 3.84–6.91 dB，归一化响应在最低受支持频点 2.225 GHz（B_full 为 2.35 GHz）高出 0 dB 0.86–3.99 dB，然后一路下滑到约 −3 dB。论文设计（40 Ω、6 mm）0–50 GHz 起伏 1.06 dB、到 B_full 3.01 dB，所有 B 都可行（B_full 时 c1=−2.38 dB、S11=−16.75 dB），J=−1.02 dB，比 J*(B_full) 低 6.39 dB。这个差距来自不同的目标，不说明论文设计次优：论文追求平坦，本实验的 J 没有平坦度约束，也不计光损耗随长度增加。
5. 事前预测的物理部分全部落空，方向一致：预测 ZL* 在 40–65 Ω，实际 23–35 Ω；预测 L* 与匹配估算相差 ≤30%，实际 B=100/150 GHz 时为 29.9 / 19.4 mm，对应估算 13.2 / 9.6 mm；预测 J*(100 GHz) 在 +4 到 +8 dB，实际 +10.43 dB。BO 预测的成功率对了，中位数比预测的 15–25 次更少。

## 2. 首个失败边界与下一步
判据没有失败，但目标函数有缺口：(a) 没有平坦度约束，优化器就用低 ZL 的倾斜响应换长度；(b) **低频支持缺口**：Z0 读数从 2.222 GHz 开始，L > c/(4·2.25·2.222 GHz) = 15.0 mm 时第一个四分之一波长特征落在 1 MHz–2.22 GHz 的无数据区，c1、c2 都没有检查到它，而全部 7 个最优点都在 15 mm 以上。所以第 2–3 条只是这组约束下的结论，不是设计建议。下一步若继续，要新编号（B06），新写边界加两条：L ≤15.0 mm（由数据覆盖推出），并给起伏设上限。不能改的：本实验的阈值、网格与已登记输出；不能把 J* 当作论文设计的改进量。

## 3. 限制
- J 只计 Vπ∝1/L，不计光损耗随长度增加（论文片上光损耗 4 dB），也不计平坦度；所以长线在构造上就占优。
- 沿用 B02 的"改长度不改截面"和 A04 的现行默认（C-01 实数 Z0、C-02 f0=1 MHz、C-03 nm 无色散）；Z0 读数缺口（例如 65–70、78–84 GHz）内的谷值看不到。
- 种子 0 最后一次迭代时，c1 的 GP 沿 L 方向的长度尺度停在上界 3.0（输入已缩放到 [0,1]）：在 GP 看来 c1 沿 L 近乎线性。BO 结论只针对这张网格和这组约束。

## 4. 对应课程概念
行波调制器的电压–带宽取舍；终端失配可以做均衡，代价是低频驱动和反射。贝叶斯优化是"探索/利用"取舍：可行概率 × 改进量。
