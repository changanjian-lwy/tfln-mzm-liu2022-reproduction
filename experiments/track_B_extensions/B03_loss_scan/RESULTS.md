# B03 - 微波损耗倍数扫描（RESULTS）

等级：`SENSITIVITY_ONLY`。范围：Track B；A04 L1 提供者，只把 α(f) 乘以 k ∈ {0.5, 1, 1.5, 2}；ZL=40/50 Ω。边界提交：`30cdcfd`。

## 0. 结论（模型敏感性）
1. 200 GHz 处 M：40 Ω 为 +0.25 / −0.87 / −1.95 / −2.96 dB，50 Ω 为 −0.78 / −1.91 / −2.97 / −3.99 dB（k=0.5/1/1.5/2）。
2. D1：40 Ω 时 k≤1 不跌破，k=1.5 为 142.4 GHz，k=2 为 121.7 GHz；50 Ω 时 k=0.5 不跌破，k=1/1.5/2 为 141.8 / 112.4 / 100.0 GHz。
3. 0–50 GHz 起伏随损耗增大：40 Ω 0.93→1.50 dB，50 Ω 1.15→2.21 dB。终端选 40 Ω 时对损耗更不敏感。
4. 最大 S11 几乎不随损耗变化（40 Ω 都在 −16.6 到 −16.8 dB）。
5. 与 B02 一致：k 倍损耗与 k 倍长度给出几乎相同的归一化响应（速度匹配时前向项只依赖 αL）。

## 2. 限制
- k 是统一倍数，真实损耗偏差可能随频率形状变化（例如导体粗糙度在高频更显著）。
- 论文说实测损耗高于仿真（C-04），但本实验的 k 不是由实测数据得到的，不能解读为"实测器件的响应"。
- 50 Ω、k=2 的 D3 括号为 92.2–103.4 GHz，未分辨。

## 3. 对应课程概念
导体损耗 ∝√f 是 TFLN 行波电极带宽的主要限制；终端略低于 Z0 可以部分补偿低频段的损耗滚降。
