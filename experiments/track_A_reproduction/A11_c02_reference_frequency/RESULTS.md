# A11 - C-02 参考频率敏感性（RESULTS）

等级：`SENSITIVITY_ONLY`。范围：只改 Eq.(4) 的参考；L1 提供者（A04）；2.22 GHz 以下用低频保持假设。边界提交：`775d1e9`。

## 0. 结论
1. **在事前固定的四个候选中，f0′=1.0 GHz 与 A05 的隐含偏移全部相容**：模型偏移 20/40/50/80 Ω/开路 = +0.46 / −0.04 / −0.12 / −0.24 / −0.41 dB，A05 = +0.59 / +0.01 / −0.13 / −0.21 / −0.45 dB，差值都在 ±0.15 dB 内（最大 0.13 dB，20 Ω）。DC、0.5 GHz、2.22 GHz 都不相容（2.22 GHz 时开路偏移 −1.14 dB，远超 −0.45 dB）。这与事前预测（"没有候选相容"）相反。
2. 这是一个**独立**的相容性：模型偏移只来自 Fig.2 输入和传输线方程，A05 的偏移只来自作者 Fig.3(a)(b) 两张图，两者没有互相拟合。它支持"作者在约 1 GHz 的有限频率归一化"的解释；A03 读数各曲线也大约从 1 GHz 开始。但这不是证明。
3. 用 1 GHz 参考重算 A04 的 Fig.3(b)：20 Ω MAE 0.757→0.318 dB，开路 0.427→0.320 dB；40/50/80 Ω 略变差（0.068→0.093、0.070→0.083、0.122→0.195 dB）。所以改参考解释了 20 Ω 和开路的大部分系统偏差，但不是"全面变好"。
4. 只报告：低频保持值（Fig.2(c) 第一个读数 46.3 Ω）上下移 2.6 Ω（2 倍中位读数误差）时，1 GHz 偏移变化约 ±0.05 dB；保持值偏低时 20 Ω 与 A05 的差变为 0.18 dB，会超出 ±0.15 dB。因此结论 1 对低频假设**处在边缘**，相容性对 20 Ω 不稳健。

## 2. 首个失败边界与下一步
没有判据失败。C-02 记为"约 1 GHz 的有限低频参考与作者两图相容（对低频保持假设处在边缘），未确认"。**主线 f0 仍为 1 MHz（DC 分压）**；是否把 C-02 升级为 1 GHz 由用户决定。如果升级，A04 的 Fig.3(b) 需要作为新实验重新评分，不能改写 A04。

## 3. 限制
- 1 GHz 低于 Z0 读数起点（2.22 GHz）和损耗读数起点（1.41 GHz），参考值依赖保持假设与输入侧拟合。
- 候选只有四个，事前固定；没有在 0.5–2.22 GHz 之间细扫，也不应该为"最佳 f0"去扫。
- A05 的隐含偏移本身来自栅格读数，有约 0.1 dB 量级的不确定度。

## 4. 对应课程概念
Eq.(4) 的 0 dB 由参考点定义：低负载在 1 GHz 时已开始"初始上升"，高负载已开始下降，参考点稍微挪动就会让整条归一化曲线平移零点几 dB。
