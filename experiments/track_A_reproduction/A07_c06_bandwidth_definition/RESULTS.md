# A07 - C-06 带宽定义诊断（RESULTS）

等级：`DIAGNOSTIC_ONLY`。范围：L1（A04 的输入与约定），只看 50 Ω 终端。边界提交：`42f09e0`。

## 0. 结论
1. 主线定义 D1（首次下穿）下，**L1 模型 141.82 GHz，Fig.3(b) 读数 141.78 GHz**，相差 0.04 GHz。这是 L1 模型与作者 Fig.3(b) 在一个有物理意义的特征上的独立一致（本实验没有为此预设判据，作为观察记录，不升级等级）。读数取下限时，D1 会提前到 132.3 GHz（133 GHz 附近的纹波谷刚好碰到 −3 dB），所以读数本身的 D1 范围是 132–142 GHz。
2. D2（此后一直低于 −3 dB）：模型和读数都截尾，终点分别为 −1.91 dB 和 −1.88 dB，即 >197.8 GHz。
3. D3（10 GHz 平滑后首次下穿）：都截尾，平滑曲线最低点为 −2.80 dB（模型，160 GHz）和 −2.77 dB（读数，162 GHz），距 −3 dB 只有约 0.2 dB。注意截尾下界只到 190.4 GHz（模型）和 194.5 GHz（读数），因为窗口在扫描末端和输入缺口处覆盖不足。
4. 按事前规则（判据 4），D2 和 D3 都"能解释" C-06：Fig.2(b) 的 202.6 GHz **与忽略纹波谷的定义相容，与首次下穿不相容**。这只是相容，不是复现：D2/D3 给的是截尾下界，不是 202.6 GHz 这个数。
5. 202.6 GHz 本身超出了 Fig.3 的 200 GHz 扫描范围，说明作者算 Fig.2(b) 时用到了 200 GHz 以上的微波参数；这部分数据论文没有给出。

## 2. 首个失败边界与下一步
没有判据失败。定义差异是 C-06 的一个**可行**解释，但不是唯一的：Fig.2(b) 的带宽也可能是用平滑或匹配的 Z0 算出来的（没有纹波，各定义就不再有差别）。下一步 A08：在 Z0=50 Ω 匹配、nm 取 Fig.2(b) 蓝线、损耗取 Fig.2(a) 的条件下，看能否复现 Fig.2(b) 整条红线。主线带宽定义仍是 D1，由用户决定是否改变；不能因为 D2/D3 与论文相容就改。

## 3. 限制
- 只看 50 Ω；其他负载的定义敏感性没有算。
- D3 的 10 GHz 窗口是事前选的，没有扫描窗口长度；窗口更短时平滑曲线会更接近 D1。
- L1 输入仍有 C-01/C-02/C-03 的现行默认；结论 1 的一致说明这些默认在 50 Ω 的 EO 曲线上足够好，不说明它们正确。
