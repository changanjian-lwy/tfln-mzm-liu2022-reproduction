# A08 - C-06 匹配提供者能否复现 Fig.2(b) 带宽曲线（RESULTS）

等级：`DIAGNOSTIC_ONLY`。范围：L1 加分支 C-06b（Z0=Zg=ZL=50 Ω，损耗不随 BCB 变，nm 无色散）。边界提交：`f714833`。

## 0. 结论
1. **在 Fig.2(a) 的损耗下，匹配的 50 Ω 线不能解释 Fig.2(b) 的带宽曲线。** 在红线读出的每个带宽频点上，匹配模型的响应是 −2.30 到 −2.50 dB（中位数 −2.38 dB），而不是 −3 dB；350 个对照点中，区间包含 −3 dB 的为 0%。
2. 设计点（BCB 1.5 µm，nm=2.2500）：在 202.6 GHz 处匹配模型为 −2.36 dB，区间 [−2.37, −2.30] dB。区间只有约 0.07 dB 宽，差距约 0.64 dB，远超损耗读数误差。
3. 只报告、不判：按 α=a√f+bf 外推（拟合残差 0.012 dB/mm），匹配模型在设计点的首次下穿约 286 GHz；各 BCB 下为 234–285 GHz。它和红线一样在 BCB≈1.5 µm 附近最高（因为那里 nm≈ng），但整体高出约 80 GHz，随 BCB 的起伏也更大（约 50 GHz，红线约 20 GHz）。这部分依赖从 198.6 GHz 到约 290 GHz 的长距离外推，只能看量级。
4. 结合 A07：C-06 的"匹配/平滑提供者"解释在本数据下不成立；"带宽定义不同"仍然可行；"作者用了不同的损耗或其他输入"既没有被排除，也没有被检验。

## 1. 判据
| # | 判据 | 结果 |
|---|---|---|
| 1 | 测试与证据重放通过；星标值取自 A06 | 通过 |
| 2 | 所有对照点 ≤205 GHz | 通过：最高 202.6 GHz（星标） |
| 3 | 所有响应有限 | 通过 |
| 4 | 星标区间含 −3 dB，且 ≥80% 对照点区间含 −3 dB | **不通过**：星标不含；对照点 0% |

## 2. 首个失败边界与下一步
判据 4 不通过，这是诊断结论本身，不是数值失败。不能因此去调高损耗、改 Z0 或 nm 来对上 −3 dB：那等于把未知输入拟合到作者曲线上（禁止事项 1）。如果以后要检验"作者用了更高的损耗"，应另立实验，并且损耗来源必须是论文中的另一条曲线（例如 Fig.6(a) 实测，属于 SC-03），而不是反推出来的倍数。

## 3. 限制
- "损耗不随 BCB 变化""nm 无色散"是假设；BCB 改变场分布，可能同时改变损耗与 Z0。
- 判据只用到 205 GHz 以内的损耗（外推 ≤3.3%），但结论 3 的带宽数字依赖长外推。
- nm 读数误差（±0.0005）没有并入区间；在 6 mm 上它对 200 GHz 响应的影响远小于 0.01 dB，不改变结论。

## 4. 对应课程概念
匹配且速度匹配的行波电极，EO 带宽只受导体损耗限制：线上总损耗约 6.4 dB 时 EO 响应下降 3 dB（论文测得的"6.4 dB 电带宽"正对应这一关系）。
