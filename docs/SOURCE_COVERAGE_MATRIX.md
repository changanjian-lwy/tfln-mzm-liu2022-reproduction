# 来源覆盖矩阵与不遗漏关卡

2026-10-04 建立（借鉴 MIHAI `SOURCE_COVERAGE_MATRIX.md`）。逐项对照论文 DOI 10.1109/LPT.2022.3178214 的四页内容，记录每一项在本项目中的角色和状态。页码为期刊页码。

## 1. 状态含义

- `LOCKED`：已与 PDF 目视核对，允许进入主线模型。
- `TEST`：已实现或已数字化，但对照尚未全部通过。
- `TRANSCRIBE`：与项目相关，尚未转录或数字化。
- `MISSING`：论文没有给出该值或实现。
- `CONFLICT`：存在两种以上可辩护的解读，登记为第 3 节的分支。
- `N/A`：只作背景，不参与 Figure 3 计算对照。

规则：主线不能在必需行仍为 `TRANSCRIBE` 时把结论升级到下一层；`MISSING` 保持为命名变量；`CONFLICT` 必须成为单独的实验分支。
