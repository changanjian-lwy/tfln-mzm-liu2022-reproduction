# 一周入门计划

目标：解释“电压 → 折射率 → 相位 → 干涉光强 → 行波频响”，并把每张图变成可重复生成、来源清楚的结果。每天建议 1.5–3 小时；数字化和参数核对可能增加时间。验收优先于日历进度。

| 天 | 交付物 | 为什么做 | 验收与边界 |
|---|---|---|---|
| 1 | 静态 MZM notebook、传输曲线、测试 | 先掌握相移与干涉，固定电压定义 | 课件例题 Vpi=2.42612 V；能量守恒；不讨论带宽 |
| 2 | 论文公式 (1)–(4) 符号和参数表 | 行波相位、反射符号和单位直接决定结果 | 明确 Vg、Zg、Z0、ZL、光学群折射率、复波数、归一化 |
| 3 | 平均驱动电压、S11 实现 | 终端反射改变沿线电压 | DC 分压、匹配无反射、无损极限；解析积分与数值积分互验 |
| 4 | 不同终端的 EO 频响 | 光与微波沿传播方向相干积累 | 使用各自同一参考频率；分别展示绝对电压和相对响应 |
| 5 | Figure 3 数字化与误差表 | 定量验证，而不是只看曲线像不像 | 记录坐标标定、点数、估计误差；不把读图点当原始数据 |
| 6 | L、RF loss、Δn 的有限扫描 | 分离损耗、走离和反射的影响 | 首次向下穿越 -3 dB；未穿越报告 >fmax；不无限外推 |
| 7 | 英文首页、技术报告、公开发布准备 | 让老师或工程师独立复现并判断边界 | 干净环境重跑；所有图有来源标签；选择代码许可证 |

本项目新建 `.venv`，不修改系统 Python 的安装。已有论文，无须重新下载；课件留在上级课程目录。通用安装和启动步骤见 README。

在当前 Mac 上，也可在 Finder 中打开项目目录，双击 `start_jupyter.command` 启动第一天笔记。首次打开等待浏览器出现 JupyterLab，然后使用 Run → Run All Cells。通用命令见 README。

## 今天怎么学

1. 打开 `notebooks/01_static_mzm.ipynb`，先读公式，再逐格运行。
2. 先手算 Δn 和 Vpi，与程序核对。
3. 将长度从 2 cm 改成 1 cm，运行最后的练习：预测 Vpi 加倍。
4. 用自己的话解释：相位变化为何需要两臂干涉才能变成输出强度变化？
5. 最后读电源分压：电源幅度 Vg 为什么不总等于器件间隙上的电压？

不要把理想曲线的零输出理解成真实器件无限消光比。课件模型只提供入门基线，后续再引入传播损耗、反射和速度失配。
