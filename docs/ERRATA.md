## E-03（2026-10-05 13:27 发现）：O01 的光模式求解用的是 3 点积分规则（数值说明，结论不变）

**问题**：`optical_fem.solve_modes` 建 ε 的 P0 基时没有指定积分阶数。femwell 的模式基继承这个基的积分规则，结果是 3 点（2 阶精确）规则，用于二阶 Nédélec/P2 单元时，质量矩阵是欠积分的。A17 的 `cpw_fem` 与 femwell 教程都显式用 `intorder=4`。
**发现方式**：写 O02 的重叠积分时，核对了 femwell 模式基的积分点数（3 点；新建的二阶基是 16 点）。
**核对**（13:26–13:30，脚本只在仓库外，没有改任何登记文件）：同一网格规则下改用 `intorder=4`，O01 名义配置 N 的 Re n_eff 变 −2.0e-6（m = 2）与 −3.6e-7（m = 1），ng 变 −3.2e-6 与 −4.3e-7。各向异性平板关卡的误差在两种积分下分别为 TE0 −7.6e-7 对 −2.6e-6、TM0 +3.3e-7 对 +2.8e-6，都远在 1e-4 的判据以内。默认积分重跑与登记值逐位一致（n_eff 1.8976164037，ng 2.2837430324）。
**影响**：O01 的判据都按实际使用的求解器配置通过（平板关卡直接对照了精确解），ng 区间端点的移动量级是 1e-6，小于 O01 的数值不确定度 u = 7.8e-6；"不定"的结论不变。O01 的文件不改。O02 的处理见其 BOUNDARY 第 5 节。
