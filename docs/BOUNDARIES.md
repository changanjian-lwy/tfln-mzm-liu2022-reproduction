## 2. 参数来源与冻结

每个输入保存 value、unit、evidence、source；模型输出另行保存，不能作为论文参数倒灌。证据类别（与 `contracts.py` 一致）：

- `paper_explicit`：论文明确给出。
- `digitized_paper_calculation`：从作者计算曲线读取；必须附数字化误差和坐标标定。
- `digitized_paper_measurement`：从作者测量曲线读取；不等于作者原始数据。
- `external_reference`：其他资料补充，只能填补论文空白，不能覆盖论文定义。
- `assumption`：显式建模假设，包括只为求解存在的数值理想化（如 A04 的 Z0(f0)=50 Ω、α(f0)=0）。
- `sensitivity_only`：仅用于扫描，不得悄悄升级为主线默认值。
- `unknown`：缺失；需要该参数的实验应报告缺失，不生成虚构曲线。

来源优先级（借鉴 MIHAI）：论文正文与图 → 论文引文（[10][15][18][19]）→ 其他直接相关文献 → 带标签的敏感性假设。敏感性假设永远不升级为论文值。

当前主线冻结值（来源细节见 [provenance](provenance.md)，未决分支见 [来源覆盖矩阵](SOURCE_COVERAGE_MATRIX.md) 第 3 节）：

| 对象 | 采用值 | 类别与限制 |
|---|---|---|
| 调制长度 L | 6 mm | paper_explicit，Fig.1(a) |
| 源 Vg / Zg | 1 V / 50 Ω | paper_explicit，Fig.3 段落与 Sec. II |
| 终端 ZL | 20/40/50/80 Ω、开路 | paper_explicit，Fig.3 图例；S11 只有四个有限负载 |

## 3. 端口、单位与工作条件（v1 保留）

- SI 内部单位：Hz、m、Ω、V、Np/m；图表可转换为 GHz、mm、dB。
- Vg 为源阻抗之前的 Thevenin 开路电压幅度，不是匹配负载读数。
- 源阻抗和 S11 参考阻抗均为 50 Ω；参考平面在均匀电极输入处。额外馈线/探针未建模时必须说明。
- 小信号、线性、正交偏置下的 EO 响应；静态余弦不能直接当 GHz 频响。
- 光学群折射率与材料相折射率不能混用；βo=ωng/c。
- 衰减系数是场幅衰减；loss[dB/mm] ×1000×ln(10)/20 转为 Np/m。
- 每个负载使用自己的参考电压，同时报告绝对电压。
- 数字化数据仅在其频率覆盖范围内插值；外推必须成为另一个假设实验。
- 正常使用 L>0、f≥0、被动负载、非负损耗。L→0 为独立极限测试，不直接计算含 1/L 的表达式。

## 4. 模型保真层级

借鉴 MIHAI 的 `P24_IDEAL` / `P25_DEVICE_AUGMENTED` 分层。每个 Track A 实验必须**只声明一层**，只用该层的参考目标评分；跨层差异另作一个量报告。

| 层 | 输入提供者 | 评分对象 | 已有实验 |
|---|---|---|---|
| L0 解析理想层 | 常数实数 Z0、常数 nm、解析损耗律 | B01–B12 解析极限；机理定性 | A01、A02 |
| L1 数字化输入层 | Fig.2 数字化 Z0(f)、α(f)；nm 按分支取值 | 数字化 Fig.3，带读数容差 | A04、A05 |
| L2 FEM 输入层 | 截面 FEM 复数 Z0(f)、nm(f)、α(f) | 同 L1，另报与 L1 输入的差 | 未开始，需 SC-01 |
| L3 网络增强层 | L1 或 L2，加馈线/焊盘/电阻二端口 | 同 L1，另报网络贡献 | 未开始，需 SC-02 |

L1 不通过不能当作 Eq.(1) 错误的证据；L0 通过也不能证明 L1 的输入与作者一致。

## 5. 运行前关卡（借鉴 MIHAI 的五问，改为本项目版本）

新建主线实验、或把结果报告为复现进展之前，在 BOUNDARY.md 中逐条回答：

1. **等效电路**：是否只有 Fig.1(c) 的源—均匀线—负载？任何额外元件（馈线、焊盘、电阻电抗）是否已命名并给出来源？
2. **端口与约定**：Vg 定义、ρ1 符号、S11 参考面、Eq.(4) 取模、f0 和每个负载的参考电压是否写明？
3. **输入提供者唯一**：每个输入角色是否只有一个提供者，并写明频率覆盖与缺口策略？常数和数字化不得混在同一基线。
4. **参数来源**：每个数是否属于第 2 节的某一类？涉及冲突分支时是否写明分支编号？
5. **结论边界**：计划的结论是否排除了测量、硬件、完整带宽和未建模机理？

任何一条回答"否"或"未定"，主线运行就被阻塞；下一步只能是来源转录，或另行命名的诊断/敏感性实验，不能凭惯例补一个约定。

## 6. 冲突与歧义分支

论文内部或论文与当前模型之间的冲突、歧义，一律登记在 [来源覆盖矩阵](SOURCE_COVERAGE_MATRIX.md) 第 3 节，编号 C-xx。规则：

- 每个分支都保持可见，不自动合并。
- A00–A05 已采用的选择记为"现行默认"，换分支必须新建实验，不能改写旧实验。
- 敏感性实验可以在授权内自行比较多个分支，等级只能是 `SENSITIVITY_ONLY` 或 `DIAGNOSTIC_ONLY`。
- 把另一分支**升级为主线默认值**由用户决定；不能因为某个分支对得更好就自行升级。

## 8. 预先定义的验收矩阵（v1 保留）

B01–B09 已在 A01 验证，B10–B12 已在 A02 验证；通过范围以各实验 RESULTS.md 为准，不代表 Figure 3 对照通过。数值阈值是工程测试选择，不是论文测量误差。

| ID | 条件 | 必须得到的结果 | 失败意味着什么 |
|---|---|---|---|
| B01 | f=0，α=0，有限正负载，不同 Z0 | Vavg=Vg ZL/(Zg+ZL) | 电压/反射符号错误 |
| B02 | Zg=Z0=ZL，α=0，nm=ng | \|Vavg\|=\|Vg\|/2，M=0 dB，S11=0 | 匹配或光微波相位约定错误 |
| B03 | ZL=Z0，α>0，nm=ng，源匹配 | \|Vavg\|/(\|Vg\|/2)=(1−exp(−αL))/(αL) | 损耗符号或幅/功率单位错误 |
| B04 | α=0、阻抗匹配，Δn≠0 | 幅值满足 \|sinc(π f Δn L/c)\|（sinc(x)=sin(x)/x） | 速度失配实现错误 |
| B05 | 开路、短路，α=0 | 负载反射分别 +1、−1；DC 电压分别 Vg、0 | 极限处理错误 |
| B06 | Vavg(f0)=0 | 归一化拒绝并报告原因 | 不允许用微小常数伪造有效频响 |
| B07 | L→0，固定有限传播参数 | Vavg 趋近 DC 分压；各个复杂相位连续 | 积分的零参数数值不稳定 |
| B08 | 实正 Z0、被动负载、非负损耗 | \|S11\|≤1；零反射的 dB 为 −∞ | 被动性或数值实现有误 |
| B09 | 一般有限参数，含失配和反射 | 解析积分与独立数值积分一致 | 公式编程错误 |
| B10 | 频率网格加密 | 有括区间的首个 −3 dB 下穿位置收敛 | 扫描分辨率不足 |
| B11 | 扫描范围内无下穿 | `>fmax` + censored=true | 不得把 fmax 当带宽 |
| B12 | 有峰化或多次交叉 | 选相对 f0 的首次下穿，列出约定 | 不得为扩大带宽改选最后一次 |

B01–B09 默认非奇异测试点 atol=1e-10 V（电压）/1e-10（无量纲），rtol=1e-8；零点用绝对误差，禁止直接用相对 dB 误差。B10 判据为网格步长减半后交叉频率变化≤0.1 GHz。Figure 3 的定量阈值必须在数字化校准后、候选输出比较前固定。

## 9. 结果等级

每个实验给出唯一等级，并同时保存 scope；任何单项通过都不能自动升级成整篇论文复现。

| 等级 | 含义 |
|---|---|
| `ANALYTIC_LIMIT_PASS` | L0 解析极限全部通过 |
| `QUALITATIVE_ONLY` | 假设输入下的机理演示 |
| `DIGITIZED_COMPARISON_PASS` | L1 及以上，所有被评分系列满足事前判据 |
| `PARTIAL_COMPARISON_FAIL` | 部分系列通过、部分失败 |
| `DIAGNOSTIC_ONLY` | 只排除或指认原因，不改基线 |
| `SENSITIVITY_ONLY` | 只显示变化方向 |
| `PARTIAL_EXTRACTION_COMPLETE` | 数字化完成但有明确缺口（数据类实验） |
| `EXPECTED_FAILURE` | 由已登记的缺失输入或分支导致的失败 |
| `BLOCKED_BY_MISSING_DATA` | 必需输入缺失，未运行 |
| `NUMERICAL_FAIL` | 收敛、有限性或被动性检查失败 |
| `PHYSICAL_BOUNDARY_FAIL` | 物理极限或约定不成立 |
| `REJECTED` | 方法有原则性错误，结果不得引用 |

## 10. 资源预算

当前所有实验单次运行都不超过 2 秒，只写本地文件，因此不设 AES 那样的 `BUDGET.json` 强制执行。BOUNDARY 仍须写明预计墙钟时间和新增磁盘；超过预计值两倍即停止并报告。SC-01 获批后，FEM 网格与运行时间必须改为 `BUDGET.json` 强制上限。

## 11. 证据组织与变更控制

采用 MIHAI/AES 的"边界先行、结果分离、旧证据只读、逐级放行"。每个实验目录 `Axx_<改变的变量>/` 或 `Bxx_<...>/` 包含：

- `BOUNDARY.md`：运行前单独提交，按 [实验模板](../experiments/EXPERIMENT_TEMPLATE.md) 填写。
- `INPUTS.md`：提交号、实际命令、输入/输出路径与 SHA-256、环境、偏离记录。
- `RESULTS.md`：逐条回答判据，含失败、偏离和不能推出的结论。
- 结构化输出（json/csv）与图；登记进 `experiments/EVIDENCE_MANIFEST.json`。

`python scripts/check_evidence.py` 核对所有已登记证据的哈希与必需文件；加 `--replay` 时在临时干净副本中重跑并要求逐字节一致。旧实验的输出被修改即为失败。后续修订须追加变更原因、时间和授权依据，不修改原判据来抹平失败。

## 12. 禁止事项

1. 把未知输入（Z0、nm、α、f0、参考电压）拟合到 Figure 3 目标上，再称为独立复现。
2. 缩放、平移或平滑目标曲线以求一致；改写图例负载值。
3. 为了更好的结果按负载分别改 f0 或归一化方式。
4. 填补数字化缺口或在覆盖范围外外推，而不另立假设实验。
5. 把 Figure 7 测量、38 Ω 实际电阻或 6.4 dB 电带宽当作 Figure 3 计算对照或 3 dB EO 带宽。
6. 覆盖或重写 A00–A05 的输出与判据。
7. 把敏感性值或输出校准后的诊断升级为基线。
8. 把 AI 生成的代码或尚未讲解的流程说成用户已独立掌握。
