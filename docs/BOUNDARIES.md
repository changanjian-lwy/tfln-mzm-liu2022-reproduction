# 论文复现边界：所有主线实验的起点

主目标：Liu et al. (2022), DOI 10.1109/LPT.2022.3178214 的公式 (1)–(4)，以及 Figure 3(a) 平均驱动电压、(b) EO 频响、(c) S11 的复现。

课件静态 MZM 是辅助物理背景，不是主线验收目标。静态模型的七项测试通过不代表论文复现已通过。

## 1. 本项目范围

- A 主线：论文等效传输线、相干平均电压、不同终端电阻、Figure 3 对照。
- B 扩展：在明确的 A 基线上扫描电极长度、RF loss、速度失配；独立参数和结果目录。
- C 辅助：课件静态相移、MZM、正交偏置，仅在解释需要时调用。
- 不含：从截面重新做 FEM、电极加工、完整实验系统、真实器件性能承诺。

Figure 3 是作者计算；Figure 7 含测量与模型外推。不能互换其验证目标。6.4 dB 电带宽不能当成 3 dB EO 带宽。

## 2. 数据和模型边界

每个输入保存 value、unit、evidence、source；模型输出另行保存，不能作为纸面参数倒灌。

- `paper_explicit`：论文明确给出。
- `digitized_paper_calculation`：从作者计算曲线读取；必须附数字化误差和坐标标定。
- `digitized_paper_measurement`：从作者测量曲线读取；不等于作者原始数据。
- `external_reference`：其他资料补充，只能填补缺失，不能覆盖论文定义。
- `assumption`：显式建模假设。
- `sensitivity_only`：仅用于扫描，不得悄悄升级为主线默认值。
- `unknown`：缺失；需要该参数的实验应报告缺失，不生成虚构曲线。

原始 FEM 数组缺失并不阻止解析极限验证、假设模型的机制演示或带不确定度的数字化复现；它限制的是逐点原始模型复现的结论。

## 3. 端口、单位与工作条件

- SI 内部单位：Hz、m、Ω、V、Np/m；图表可转换为 GHz、mm、dB。
- Vg 为源阻抗之前的 Thevenin 开路电压幅度，不是匹配负载读数。
- 源阻抗和 S11 参考阻抗均为 50 Ω；参考平面在均匀电极输入处。额外馈线/探针未建模时必须说明。
- L=6 mm 是论文基准；ZL=20/40/50/80 Ω 与开路对应 Figure 3(a,b)，S11 对照为四个有限负载。
- 小信号、线性、正交偏置下的 EO 响应；静态余弦不能直接当 GHz 频响。
- 光学群折射率与材料相折射率不能混用；βo=ωng/c。
- 衰减系数是场幅衰减；loss[dB/mm] ×1000×ln(10)/20 转为 Np/m。
- f0=1 MHz 是当前项目明确选择，论文允许 DC 或 MHz 量级参考。各负载使用自己的参考电压，同时报告绝对电压。
- 数字化数据仅在其频率覆盖范围内插值；外推必须成为另一个假设实验。
- 正常使用 L>0、f≥0、被动负载、非负损耗。L→0 为独立极限测试，不直接计算含 1/L 的表达式。

## 4. 预先定义的验收矩阵

当前 B01–B09 已在 A01 验证，B10–B12 已在 A02 验证；通过范围以各实验 RESULTS.md 为准，不代表 Figure 3 对照通过。数值阈值是工程测试选择，不是论文测量误差。

| ID | 条件 | 必须得到的结果 | 失败意味着什么 |
|---|---|---|---|
| B01 | f=0，α=0，有限正负载，不同 Z0 | Vavg=Vg ZL/(Zg+ZL) | 电压/反射符号错误 |
| B02 | Zg=Z0=ZL，α=0，nm=ng | \|Vavg\|=\|Vg\|/2，M=0 dB，S11=0 | 匹配或光微波相位约定错误 |
| B03 | ZL=Z0，α>0，nm=ng，源匹配 | \|Vavg\|/(\|Vg\|/2)=(1−exp(−αL))/(αL) | 损耗符号或幅/功率单位错误 |
| B04 | α=0、阻抗匹配，Δn≠0 | 幅值满足 \|sinc(π f Δn L/c)\|（sinc(x)=sin(x)/x） | 速度失配实现错误 |
| B05 | 开路、短路，α=0 | 负载反射分别 +1、−1；DC 电压分别 Vg、0 | 极限处理错误 |
| B06 | Vavg(f0)=0 | 归一化拒绝并报告原因 | 不允许用微小常数伪造有效频响 |
| B07 | L→0，固定有限传播参数 | Vavg 趋近 DC 分压；各个复杂相位连续 | 积分的零参数数值不稳定 |
| B08 | 实正 Z0、被动负载、非负损耗 | \|S11\|≤1；零反射的 dB 为 −∞ | 被动性或数值实现有误 |
| B09 | 一般有限参数，含失配和反射 | 解析积分与独立数值积分一致 | 公式编程错误 |
| B10 | 频率网格加密 | 有括区间的首个 −3 dB 下穿位置收敛 | 扫描分辨率不足 |
| B11 | 扫描范围内无下穿 | `>fmax` + censored=true | 不得把 fmax 当带宽 |
| B12 | 有峰化或多次交叉 | 选相对 f0 的首次下穿，列出约定 | 不得为扩大带宽改选最后一次 |

B01–B09 默认非奇异测试点 atol=1e-10 V（电压）/1e-10（无量纲），rtol=1e-8；零点用绝对误差，禁止直接用相对 dB 误差。B10 初始判据为网格步长减半后交叉频率变化≤0.1 GHz，实际实验先声明范围与步长；若不满足继续加密或报告未收敛。Figure 3 的定量阈值必须在数字化校准后、候选输出比较前固定，不能事后放宽来获得通过。

## 5. 实验必须先写边界，再运行

每个实验目录先提交 `BOUNDARY.md` 和配置，写明：父实验、问题、唯一变化（或完整联合变量）、固定参数、来源、成功条件、失败条件、不能证明什么。

结果另记 `RESULTS.md`：实际输入、执行是否成功、每项判据、首次失败位置、误差、下一步。保留失败结果；新变体另建实验，不覆盖已验收父实验。不允许为了图像好看更改源电压、参考频率、损耗或负载而不建新配置。

结论等级分开：`ANALYTIC_LIMIT_PASS`、`QUALITATIVE_ONLY`、`DIGITIZED_COMPARISON_PASS`、`SENSITIVITY_ONLY`、`BLOCKED_BY_MISSING_DATA`、`NUMERICAL_FAIL`、`PHYSICAL_BOUNDARY_FAIL`。同时保存 scope，任何单项通过都不能自动升级成整篇论文复现。
